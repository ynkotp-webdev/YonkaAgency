# 21. SEO Blueprint

> ⚠️ **Стратегический слой этого документа частично устарел.**
> Реальные вводные: чек **$200–300** (не $1–5k), цель — **прогрев холодных контактов**
> (не органический трафик), исполнитель — один человек. Актуальная стратегия:
> **[`25-revised-strategy.md`](25-revised-strategy.md)**.
> Фактура и измерения в этом файле остаются в силе.

**Домен:** `yonkaagency.com.ua` (обоснование — `17-recommended-sitemap.md` §5)
**Языки:** uk основной + ru + `x-default` · **База:** Львів

## 1. Отправная точка: что данные показали о нише

**Порог входа по ссылкам низкий.** У S2 SEOK всего **16 ссылающихся доменов** — столько же,
сколько у S5 Fabryka, — и при этом **39 365 визитов против 642** (`24-serpstat-market-data.md`).
R4 theDC держит #2 по «розробка сайтів під ключ Київ», имея **5 доноров**.

**Трафик даёт охват коммерческих интентов, а не число страниц.**
SEOK: 8 579 ключей → 39 365 визитов (**4,59 визита на ключ**, в 10 раз выше рынка).
Wezom: 236 991 ключ → 92 967 визитов (0,39 на ключ).

**Головной запрос низкочастотный** — «створення сайтів під ключ» всего **170/мес**,
восьмой по объёму. Ориентироваться на него как на главную цель нельзя.

**Следствие:** технический SEO — обязательная гигиена; основная работа — правильно выбрать
набор коммерческих интентов и закрыть каждый отдельной полной страницей.

## 2. Технический минимум

Всё это есть у лучших и отсутствует у худших (E4, E6, E16.2):

- [ ] `robots.txt` — реальный файл, не soft-404 (у S6 отдаёт HTML с кодом 200 + краулинговая ловушка)
- [ ] `sitemap.xml` с разбивкой по типам
- [ ] `canonical` на каждой странице (нет у S5 — и он #1)
- [ ] `hreflang` uk / ru / **`x-default`** (корректный `x-default` только у 3 из 11)
- [ ] Open Graph + Twitter Card (у S5 и S6 — ноль)
- [ ] **`Content-Signal: ai-train=no, search=yes, ai-input=yes`** в robots.txt — делает 1 из 11 (S4)
- [ ] Все навигационные ссылки — реальный `href` (провал `crawlable-anchors` у 6 из 11)
- [ ] Title ≤ 60 символов (у S2 — 88, у R3 — 126: обрежутся)
- [ ] Description 150–160 символов, как оффер, а не набор эмодзи
- [ ] Иерархия H1 → H2 → H3 используется (у S2 H3 и H4 не используются вообще)
- [ ] Все изображения с `alt` (провал `image-alt` у S4, S5, R4)
- [ ] Год в title и в футере совпадают (у S6 «ціна 2025» при «© 2026»)

## 3. Schema.org — полный набор

Собран из лучших решений всей выборки. Ни один сайт не имеет всего сразу.

| Тип | Где | Кто уже делает |
|---|---|---|
| `Organization` + **`LocalBusiness`** + **`GeoCoordinates`** + **`OpeningHoursSpecification`** | Все страницы | **только R1 Wezom** (E16.2) |
| **`Offer` / `AggregateOffer` / `PriceSpecification`** | `/tsiny/` и карточки услуг | S2, R3 — 2 из 11 |
| `FAQPage` | Главная, услуги | R1, R4 |
| `BreadcrumbList` | Все внутренние | S1, S2, S4, S6 |
| `Person` | Страницы команды | S2 |
| `AggregateRating` + `Review` | Отзывы | R2, R5 |
| `ProfessionalService` | Гео-страницы | R5 |

**Локальный пакет для Львова** — приоритет: `LocalBusiness` + `GeoCoordinates` +
`OpeningHoursSpecification` + физический адрес. Единственный из 11, кто собрал это
целиком — R1 Wezom, и он же держит #1 по двум коммерческим запросам.

с 5-го места на 9-е. Запросы «сайт для стоматології», «сайт для салону краси» не набрали
измеримой частотности. Страницы делать стоит — но как материал для продаж и доверия,
а не как SEO-канал.

## 5. Ценовая страница — как строить

Модель R3 iFish, лучший контент выборки (Content 92/100), **#1** по ценовому запросу:

- **4 381 слово**, 46 H2 + 48 H3, оглавление на странице
- сегментация рынка по бюджетам (Бюджет / Бізнес / Преміум)
- разбор из чего складывается цена: домен, хостинг, CMS, дизайн, вёрстка, наполнение
- почасовые ставки
- разметка `Product` + `AggregateOffer` + `AggregateRating`

**Что у него взять:** глубину, оглавление, разбор составляющих цены, разметку `Offer`.
**Чего не брать:** 47,7 мобильных экрана, 441 изображение с нулевым `lazy`,
1 890 КБ неиспользуемого JS и **нерабочую форму** (E17.3).

## 6. Гео-архитектура

Модель R5 Rubik — единственная масштабируемая в выборке, **проверена как не-дублирующая** (E23.1):

```
/lviv/rozrobka-saitiv/
/lviv/internet-magazyn/
/kyiv/rozrobka-saitiv/
```

**Дисциплина обязательна.** У Rubik страницы городов различаются:
- **ценой в разметке `Offer`** — Черкаси 50–200 тыс. грн, Київ **70–250 тыс. грн** (+40%);
- **структурой title**, а не подстановкой топонима;
- **кейсами** и частью блоков;
- объёмом ~370 слов.

Шаблонная подстановка «{місто}» в один и тот же текст даст дубли, которые Google режет.

**Старт — Львів** (домашний рынок), расширение — после проверки модели.

## 7. Внутренняя перелинковка

| Связь | Направление |
|---|---|
| Главная → все услуги | карточки в блоке 4 |
| Услуга ↔ цена | из карточки услуги в `/tsiny/` и обратно в конкретный тариф |
| Услуга → кейс той же услуги | контекстная ссылка «як це виглядало у клієнта» |
| Кейс → услуга + индустрия | двойная связка |
| Индустрия → услуги + кейсы этой отрасли | хаб отрасли |
| Гео → услуги + локальные кейсы | хаб города |
| Блог → коммерческая страница по теме | из статьи в услугу, не наоборот |
| Футер → карта сайта | приём R4 theDC (65 ссылок); у S3 футера нет вообще |

**Хлебные крошки на всех внутренних** — есть только у 4 из 11 (S1, S2, S4, S6).

**Чего избегать:** тег-архивы без `noindex` — у S1 их 217, это 16% сайта и риск
каннибализации коммерческих страниц (E5.1).

## 8. Контент

**Объём не решает.** Страница S5 на 984 слова стоит выше страницы S2 на 2 858 слов (E15.1).
Ориентир: **1 500–2 500 слов** на коммерческую страницу, **3 000+** на ценовую.

**E-E-A-T** — делают 4 из 11:
- персональные страницы команды (S1 — 96 страниц, сильнейший сигнал выборки);
- лицо основателя в первом экране (R3);
- разметка `Person` (S2);
- физический адрес + `LocalBusiness` (R1).
