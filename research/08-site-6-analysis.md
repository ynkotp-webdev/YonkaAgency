## Роль в исследовании

**Нижняя граница рынка** — и одновременно **самый чистый пример того, почему метрику
Performance нельзя читать в отрыве от содержания**.

Худший сайт выборки по девяти критериям из одиннадцати. При этом занимает шестое место
в топе по головному коммерческому запросу.

## Единственная «сильная» сторона — и та мнимая

**Performance 70/100** (Lighthouse: 84 mobile, **100 desktop**) — формально третий результат
выборки. Разбор (E19.2, E17.1):

**Это скорость пустоты, а не результат оптимизации.** Сайту нечего грузить.
Именно поэтому в оценке выставлено 70, а не 84–100: балл отражает измерение, но не инженерию.

Также: **Best Practices 100/100** — по той же причине.

## Слабые стороны

**SEO 22 — техническая база отсутствует полностью** (E4, E6):
- **нет robots.txt**: `/robots.txt` отдаёт **HTML главной страницы с кодом 200** —
  soft-404 из catch-all роутинга ASP.NET. Lighthouse независимо провалил аудит `robots-txt` (E19.4)
- **краулинговая ловушка**: ссылки резолвятся в `/robots.txt/about`, `/robots.txt/services`,
  `/robots.txt/portfolio` и далее рекурсивно — бесконечное пространство URL
- **нет sitemap**
- **нет schema, нет Open Graph, нет hreflang** — при физически существующем переключателе uk/ru
- **418 слов** на коммерческой странице против 2 858 у SEOK — **в 7 раз меньше**
- description 197 символов — обрежется
- title и description говорят «ціна **2025**», в футере «© 2026» — контент не обновлялся

**Conversion 18 — на целевой коммерческой странице нет ни одной CTA.**
Автоматический поиск по всем конверсионным формулировкам не нашёл ни одной кнопки (E21).
**Ноль форм, ноль `tel:`, ноль `mailto:`** (E10). Связаться можно только через чат-виджет.

**Technical 22 — мёртвый стек** (E12): Bootstrap 3, jQuery, Font Awesome 4, `prettyPhoto`,
`lytebox` и **полифилы для Internet Explorer 8** с домена `oss.maxcdn.com`, который больше
не обслуживается. Шаблон ~2014–2015 года. **Ноль `<main>`**.

**UI 18 — визуальный возраст 2014** (E17.6): зелёные полосы, сайдбар-список, скриншоты
сайтов в мокапах устройств десятилетней давности. **Единственный сайт выборки на системных
шрифтах** — Arial и Verdana (E17.5).

**Контраст:** пункты меню `#174772` на зелёном `#08AE01` — **3,24:1** при норме 4,5 (E20.1).

**Индикатор фокуса снят** — 0 из 5 (E18.1).

## Что забрать

Ничего по реализации. Единственное содержательное — **таблица цен со сроками**
(лендінг від 12 000 грн / від 10 днів, багатосторінковий від 15 000 грн, інтернет-магазин
від 20 000 грн — E22.1): формат «услуга — срок — цена» правильный, наполнение и вёрстка нет.

## Чего не повторять

1. **robots.txt, отдающий HTML с кодом 200** — и краулинговая ловушка из него.
2. Отсутствие sitemap, schema, Open Graph, hreflang.
3. **Коммерческая страница без единой CTA и без форм.**
4. 418 слов на странице, продающей услугу за десятки тысяч гривен.
5. Полифилы IE8 и библиотеки 2014 года в продакшне.
6. Год в title, который не совпадает с годом в футере.
7. Системные шрифты как единственная типографика.

## Урок для оценочной системы

ISDL — причина, по которой **Lighthouse Performance нельзя использовать как метрику
качества сайта**. Худший сайт ниши получает 100/100 на десктопе. Скорость измеряет
доставку, а не ценность доставляемого.
