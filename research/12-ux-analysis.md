## 3. Навигация

**Три модели меню** (E18.2):

1. **По типу сайта** — S3, S4, S6, R4, S5, R5 (6 из 11). Подменю «Послуги» = Лендінг ·
   Візитка · Корпоративний · Інтернет-магазин. Прямое отражение поискового спроса.
2. **По цене** — R3 iFish, уникально: в верхнем меню «Ціни WEB / SEO / SMM / PPC».
   Сайт из 65 URL занимает #1 по ценовому запросу.
3. **Минимальная** — S2 SEOK: 4 пункта, глубина в мега-меню, а в самом пункте —
   **счётчик «Кейси 153»**.

**Футер как навигация** — разброс 65 → 0 ссылок: R4 делает из футера карту сайта (65),
**у S3 тега `<footer>` нет вообще**.

**Уникальные разделы:** «Команда» (S1, 96 страниц), «Індустрії» и «Технології» (S4),
«Освіта» (S6), «Showreel» (R2), «Юридичний супровід» и «AI-лендинг за 1–2 дні» (R4).

## 6. Выводы для собственного сайта

1. **Первый экран чистый.** Единственный сайт без оверлеев — лучший по конверсии.
2. **Форма — 3–5 полей.** Бриф второй ступенью, не первой.
3. **Цена до формы** (приём S2) — снимает главное возражение раньше запроса контактов.
4. **`tel:` на каждой странице.** Три сайта из одиннадцати теряют мобильный звонок.
5. **Хлебные крошки** — делают 4 из 11.
6. **Длина 12–14 мобильных экранов** — верхняя граница разумного.
7. **Счётчик кейсов в навигации** — доказательство видно на каждой странице.
